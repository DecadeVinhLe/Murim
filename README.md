# vinh-jianghu-portfolio

Le Tran Lam Vinh's portfolio: four pages (home, about, projects, contact) in a murim / cultivation martial-arts mood: a storm-night moon over a mountain temple, red seal chops, a bagua clock and a vinyl music player.

## Files
- css/style.css  all styles (dark and light looks, switched by the sun/moon button)
- js/scene.js    background: dark mode shows assets/img/bg-moon.jpg (moon over the temple), light mode shows assets/img/bg-karst.jpg (misty peaks), with drifting cloud, fog, embers, rain and film grain on top
- js/seal.js     red seal chops (SVG, Chinese glyphs) used instead of icons
- js/main.js     top bar, bagua clock, full-screen menu, page transitions
- js/player.js   vinyl player; the default track is assets/audio/hien-thien-duyen.mp3
- assets/        images, logos, audio

## Run
Open index.html, or serve the folder: `python3 -m http.server`.
